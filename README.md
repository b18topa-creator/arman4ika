# Арқан тартыс Online

Арқан тартыс және Қамал қорғау. Жеке матч пен бөлек турнир режимі, 64 қатысушыға дейін, бір уақытта 32 жекпе-жек. Әр турнир кезеңіне бөлек сұрақтар; Excel, JSON, CSV және арнайы PDF үлгісін импорттау.

Node.js 24: `npm start`. Порт: `PORT` не 4174. `npm run build` синтаксисті тексереді. Қосымша тәуелділік қажет емес. SQLite бөлмелері `.data/rooms.sqlite` ішінде. Render Free жергілікті деректері қайта іске қосылғанда жойылуы мүмкін.

Оқушылар тек өз жауабын жібереді. Ұпай серверде саналады. Бөлме иесі турнирдің әр кезеңін өзі жалғастырады.
