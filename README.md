# Bilim Arena · Арқан тартыс Online

Арқан тартыс және Қамал қорғау. Жеке матч және турнир режимі. 100 қатысушыға дейін, бір уақытта 50 жекпе-жек. Жұпсыз қалған оқушы кезеңнен автоматты өтеді; оған ұпай мен жекпе-жек жеңісі қосылмайды. Келесі кезеңді мұғалім «Жалғастыру» батырмасымен бастайды.

Турнир соңында мұғалім мен барлық оқушыға үздік бес қатысушы көрсетіледі. Рейтинг бүкіл турнирдің қабылданған нәтижелерін есептейді: чемпион, жеткен кезең, жекпе-жек жеңістері, жалпы ұпай, содан кейін дұрыс жауаптарға кеткен уақыт. Толық тең нәтижелер бір орынды бөліседі; бесінші жолмен тең қалған қатысушылар бөлек мәтінде көрсетіледі. Қатысушы саны бестен аз болса, барлық ойнаған оқушы көрсетіледі. Көрермендер рейтингке кірмейді. Қайта ойнатылған тең матчтың орнына соңғы қабылданған нәтиже есептеледі.

Әр кезеңге бөлек сұрақтар: бір Excel, JSON, CSV немесе арнайы PDF файлымен барлық 7 кезеңді жүктеуге болады. Excel-де «Кезең» бағаны кезең нөмірін береді. Басталған кезең бекітіледі, келесі кезеңдерді өңдеуге болады.

Арқан тартыста 5 ұпай айырмасы, Қамал қорғауда 7 дұрыс жауап жеңіс береді. Сұрақтар таусылса, ұпайы көп жақ жеңеді; тең ұпайда дұрыс жауап уақыты есептеледі. Оқушылар өз жауабын ғана жібереді. Ұпай мен қорытынды рейтинг серверде есептеледі.

Node.js 24, қосымша тәуелділіксіз. npm start — серверді іске қосу; npm run build — синтаксисті тексеру. PORT не 4174. SQLite: .data/rooms.sqlite. Render Free жергілікті деректері қайта іске қосылғанда жойылуы мүмкін.

Нұсқа: 3.2.0. Турнир рейтингі, тақ қатысушы саны, барлық 2–100 қатысушы өлшемі, қайта ойнату, API қолжетімділігі және SQLite-ден қалпына келтіру тексеріледі.
