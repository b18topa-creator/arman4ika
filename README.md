# Арқан тартыс Online · Bilim Arena

Арқан тартыс және Қамал қорғау. Жеке матч пен бөлек турнир режимі, 100 қатысушыға дейін, бір уақытта 50 жекпе-жек.

Турнирде қарсылассыз қалған оқушы осы кезеңнен автоматты түрде өтеді. Оған жасанды ұпай қосылмайды. Мұғалім автоматты өткен оқушыны және барлық жекпе-жектің нәтижесін көреді. Келесі кезең тек мұғалім «Жалғастыру» басқанда басталады. 100 қатысушыға 7 кезең жеткілікті.

Бір Excel, JSON, CSV немесе арнайы PDF үлгісінде барлық кезеңнің сұрақтары беріледі. Excel-дегі «Кезең» бағанына 1, 2, 3 және т.б. жазылады. Сайт сұрақтарды сол кезеңдерге бөледі. Дайын Excel және PDF үлгілерінде 7 кезең, әр кезеңге 10 сұрақ бар. Кейінгі кезеңдердің сұрақтарын ойын барысында да өңдеуге болады; басталған кезең бекітіледі.

Арқан тартыста 5 ұпай айырмашылығы жеңіс әкеледі. Қамал қорғауда 7 дұрыс жауап жеңіске жеткізеді. Әр дұрыс жауап 1 ұпай; сұрақтар біткенде ұпай мен жауап беру уақыты ескеріледі. Оқушылар тек өз жауабын жібереді, ұпай серверде саналады.

Node.js 24: `npm start`. Порт: `PORT` не 4174. `npm run build` синтаксисті тексереді. Қосымша тәуелділік қажет емес. SQLite бөлмелері `.data/rooms.sqlite` ішінде. Render Free жергілікті деректері қайта іске қосылғанда жойылуы мүмкін.

3.1 нұсқасы: 2–100 қатысушыға арналған барлық турнир өлшемі, 7 кезеңдік толық турнир, бір мезгілде 100 оқушының кіруі мен жауап беруі және Excel/PDF кезеңдері автоматты тексерілді.
